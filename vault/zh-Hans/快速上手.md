# 快速上手

1. 在 Obsidian 选择「打开文件夹作为库」，选本文件夹（`vault/zh-Hans`）。打开后先看 [[Start Here]]。
2. 设置 → 第三方插件：确认 **Archaeo Doc Parser**、**Archaeological Tomb Parser**、**Templater**、**Style Settings** 已启用。这四个已经打包在库里，一般不用再安装。
3. 设置 → 外观：主题应为 **Still**。如需调整中文排版，打开 Style Settings，找到 Still 的「中文排版」「中文字体搭配」。本库默认已打开中文排版。
4. 打开 [[Inbox/示例墓葬文本]]，命令面板运行 **Parse archaeological tombs**。结果会出现在 `Tombs/示例墓葬文本_tombs/`。
5. 新建笔记时，命令面板用 **插入模板**（核心模板）或 **Templater: Insert template**，选 `Templates/` 里对应的模板。Templater 也配置了：在 `Tombs/`、`Sites/`、`Artifacts/`、`Inbox/` 里新建文件时可用对应模板（需在 Templater 设置里打开「Trigger on file creation」才会自动套用；默认关闭，避免打扰）。

还要把 PDF 转成 Markdown 时：把文件放进 [[Inbox]]，右键 **Parse to Markdown**。免费档不用填 token，也不要把 key 写进这个库。
