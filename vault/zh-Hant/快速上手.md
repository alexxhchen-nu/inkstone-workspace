# 快速上手

1. 在 Obsidian 選擇「開啟資料夾作為儲存庫」，選本資料夾（`vault/zh-Hant`）。開啟後先看 [[Start Here]]。
2. 設定 → 第三方外掛：確認 **Archaeo Doc Parser**、**Archaeological Tomb Parser**、**Templater**、**Style Settings** 已啟用。這四個已經打包在庫裡，一般不必再安裝。
3. 設定 → 外觀：主題應為 **Still**。如需調整中文排版，開啟 Style Settings，找到 Still 的「中文排版」「中文字體搭配」。本庫預設已開啟中文排版。
4. 開啟 [[Inbox/示例墓葬文本]]，命令面板執行 **Parse archaeological tombs**。結果會出現在 `Tombs/示例墓葬文本_tombs/`。示例正文保持簡體，因為解析器目前依簡體關鍵詞辨認形制和尺寸。
5. 新建筆記時，命令面板用 **插入範本**（核心範本）或 **Templater: Insert template**，選 `Templates/` 裡對應的範本。Templater 也設定了：在 `Tombs/`、`Sites/`、`Artifacts/`、`Inbox/` 裡新建檔案時可用對應範本（需在 Templater 設定裡開啟「Trigger on file creation」才會自動套用；預設關閉，避免打擾）。

還要把 PDF 轉成 Markdown 時：把檔案放進 [[Inbox]]，右鍵 **Parse to Markdown**。免費方案不必填 token，也不要把 key 寫進這個庫。
